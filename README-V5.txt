BIBI KREATIVWERKSTATT – VERSION 5

Jetzt kann Pages CMS nicht nur Produkte, sondern auch die festen Inhalte der Homepage bearbeiten.

Im Bereich "Homepage" bearbeitbar:
- Startbereich: Texte, Button-Text, großes Bild
- Shop-Überschrift
- Über mich: alle Texte und Bild
- Vorteile: Symbole, Überschriften und Untertexte
- Kontakt: Texte, Instagram und E-Mail
- Footer: Logo und Name

Im Bereich "Produkte":
- Produktfoto
- Produktname
- Preise
- Beschreibung
- Kennzeichnung
- verfügbar / ausverkauft
- im Shop anzeigen / verstecken

Das Layout, Farben und die Anordnung bleiben im Code geschützt, damit beim Bearbeiten nichts versehentlich kaputtgeht.
