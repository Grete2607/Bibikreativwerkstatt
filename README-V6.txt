Einmalige Einrichtung für automatische E-Mail:
1. Auf formspree.io ein Konto erstellen.
2. Neues Formular für Bestellungen anlegen.
3. Benachrichtigungsadresse: bibikreativwerkstatt@gmail.com
4. Form-Endpunkt kopieren, z. B. https://formspree.io/f/abcdefgh
5. In script.js suchen:
   const ORDER_FORM_ENDPOINT = "FORM_ENDPOINT_HIER_EINTRAGEN";
6. Den Platzhalter durch den echten Endpunkt ersetzen.
7. Commit changes.

Danach erhält Bibi bei jeder Bestellung automatisch eine E-Mail von Formspree.
