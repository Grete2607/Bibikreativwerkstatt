BIBI KREATIVWERKSTATT – VERSION 4

Diese Version ist für Pages CMS vorbereitet.

Neu:
- Produkte werden aus products.json geladen.
- Produktfoto, Name, Preis, Beschreibung, Verfügbarkeit und Sichtbarkeit können über Pages CMS gepflegt werden.
- Ausverkaufte Produkte bleiben sichtbar, können aber nicht in den Warenkorb gelegt werden.
- Produktbilder liegen im Ordner media.

So geht es weiter:
1. Den Inhalt dieses ZIPs in das bestehende GitHub-Repository hochladen und vorhandene Dateien ersetzen.
2. Warten, bis GitHub Pages die Änderung veröffentlicht hat.
3. Danach Pages CMS einrichten und mit dem Repository verbinden.

Wichtig:
Die Datei .pages.yml muss ebenfalls hochgeladen werden. Sie steuert den Verwaltungsbereich.
